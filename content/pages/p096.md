# 範例阿斯提爾：小騎槍

## 小騎槍（Lance-Minor）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 元素 |
| 核心 | 自然 |
| 能量 | 2 |
| 狀態欄 | 過熱 |
| 零件 A | 熱量凝縮器：清除阿斯提爾的「過熱」勾選 |
| 零件 B | 繁飾組件：擲出相同點數的骰子時，恢復 1 能量 |

這款英勇的機體配備可穿透裝甲的長騎槍，擅長從遠方衝向敵人，給予決定性一擊。長度讓它難以打擊近敵，因此備有副武器提供防禦火力，牽制敵人。

### 動作：慣性驅動（Inertia Drive）

為了超越、突進或閃避而「挺過風暴」，擲出 12+ 時，恢復 1 能量。

### 武器

- **手持：亞登特穿刺槍（Ardentpiercer）III**：近戰／衝擊、決勝、架設、耗能（melee / impact, decisive, set-up, drain）。
- **手持：力能連射器（Force Repeater）III**：遠射／防禦、無力（ranged / defensive, weak）。

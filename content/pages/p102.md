# 範例阿斯提爾：鳥籠

## 鳥籠（Birdcage）IV

| 欄位 | 內容 |
| --- | --- |
| 路數 | 神聖 |
| 核心 | 古代 |
| 能量 | 2 |
| 狀態欄 | 過熱 |
| 零件 A | 秘器：天使項圈（Angel Collars） |
| 零件 B | 使魔矩陣：受縛天使（Bound Angels）IV |

許多人認為，阿斯提爾這個概念很危險，甚至邪惡。很少有機體能像鳥籠一樣，讓這種判斷如此容易。它是沉重的步行機，幾乎沒有自身武裝，卻以一群被束縛、套上項圈的天使補足火力；天使在真正死亡的威脅下被迫服役。這些機器很殘酷，它們的引導者更加殘酷。

### 動作：束縛儀式（Binding Rituals）

以「子系統」啟動「天使項圈」時，可以清除一項與受縛天使有關的風險。

### 武器

- **手持：龐然身軀（Hulking Form）IV**：近戰／剋敵、貼身（melee / bane, intimate）。
- **矩陣：受縛天使（Bound Angels）IV**：遠射／防禦、顯眼（ranged / defensive, distinct）。

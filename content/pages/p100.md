# 範例阿斯提爾：弄臣

## 弄臣（Jester）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 奧術 |
| 核心 | 結晶 |
| 能量 | 0 |
| 狀態欄 | 過熱 |
| 零件 A | 抗性護符：壓力調節器（Pressure Regulator）；降低加速造成的危難 |
| 零件 B | 複雜術式：弄臣浮空術的構件 |

嵌入減輕重量的法術石，讓弄臣擅長保持機動。它能短距懸浮，以多數阿斯提爾難以想像的靈活度移動。多數長年駕駛弄臣的引導者，都會發展出近乎超自然的戰場站位直覺。

### 動作：浮空術（Lev-Spells）

駕駛這架阿斯提爾時，可以使用斥候扮演書的「機動（mobility）」動作。

### 武器

- **手持：巨型彎刃劍（Dire Shotel）III**：近戰／毀滅、雙手、耗能（melee / ruin, 2H, drain）。
- **收於套中：蛇怪長槍（Basilisk Lance）III**：遠射／剋敵、束縛、耗能、雙手（ranged / bane, restraining, drain, 2H）。

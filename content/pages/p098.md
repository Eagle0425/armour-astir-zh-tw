# 範例阿斯提爾：預兆

## 預兆（Omen）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 凡俗 |
| 核心 | 煉金 |
| 能量 | 3 |
| 狀態欄 | 過熱 |
| 零件 A | 標準化零件：休整時 +1 枚代幣，只能用於維修 |
| 零件 B | 奧術熔爐：可以「冷卻」，替耗用掉的武器補給 |

相較其他阿斯提爾，預兆的設計略顯樸素，卻以容易保養維修聞名。加上大量使用常見零件，預兆或相似機體，通常構成任何有組織阿斯提爾部隊的主力。

### 動作：通用零件（Generic Parts）

修理或保養預兆而「冷卻」時，帶著自信行動。

### 武器

- **手持：掌心弩槍（Palm Bolter）III**：遠射（ranged）。
- **手持：導管之刃（Conduit Blade）III**：近戰／剋敵、耗能（melee / bane, drain）。

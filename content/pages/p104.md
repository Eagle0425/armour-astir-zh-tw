# 範例阿斯提爾：美杜莎

## 美杜莎（Medusa）IV

| 欄位 | 內容 |
| --- | --- |
| 路數 | 褻瀆 |
| 核心 | 邪術 |
| 能量 | 0 |
| 狀態欄 | 過熱 |
| 零件 A | 使魔矩陣：蝮蛇使魔（Adder Familiars）IV |
| 零件 B | 法術常式：「決定性打擊」時可選擇直接採用 7–9 |

受魔法驅動的蛇群保護、具備石化魔法的美杜莎，理所當然地令人畏懼。即便最有天分的駕駛者，接近它的凝視也會置身風險。

### 動作：石化核心（Petrifier Core）

「交鋒過招」時，可以承受劣勢，讓對手在你擲出 6− 時承受風險「受束縛」。

### 武器

- **手持：蛇髮女妖的凝視（Gorgon's Glare）IV**：遠射／剋敵、束縛、雙手、耗能（ranged / bane, restraining, 2H, drain）。
- **矩陣：蝮蛇使魔（Adder Familiars）IV**：遠射／範圍、有限（ranged / area, limited）。

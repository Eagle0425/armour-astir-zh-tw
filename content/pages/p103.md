# 範例阿斯提爾：刀刃傑克

## 刀刃傑克（Jack-of-Blades）IV

| 欄位 | 內容 |
| --- | --- |
| 路數 | 凡俗 |
| 核心 | 古代 |
| 能量 | 3 |
| 狀態欄 | 過熱 |
| 零件 A | 抗性護符：瞬鑄爐（Flashforge）；降低近戰武器斷裂造成的危難 |
| 零件 B | 額外手臂：+2 條手臂 |

刀刃傑克很少以鋒利、碎裂金屬風暴以外的模樣出現在人們眼前。這種奇特的阿斯提爾，專為使用脆弱武器而設計，戰鬥中反覆將武器折斷、重鑄。刀刃內的能量通道能重新利用通常在排熱時流失的魔力；成對武裝捨棄防守、專注攻擊，因此很少有東西能在刀刃傑克面前站立太久。

### 動作：灼印之刃（Branded Blades）

清除「過熱」勾選時，你下次「交鋒過招」或「決定性打擊」獲得優勢。

### 武器

- **手持：成對刀刃（Paired Blades）IV**：近戰／防禦、雙手（melee / defensive, 2H）。
- **手持：成對短刀（Paired Knives）IV**：近戰／剋敵、決勝、貼身、雙手（melee / bane, decisive, intimate, 2H）。

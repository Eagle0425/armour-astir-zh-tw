# IV 階範例阿斯提爾：追獵者

## 追獵者（Pursuer）IV

| 欄位 | 內容 |
| --- | --- |
| 路數 | 褻瀆 |
| 核心 | 邪術 |
| 能量 | 3 |
| 狀態欄 | 過熱 |
| 零件 A | 護禦：影紗（Shadowveil）；+守護（ward） |
| 零件 B | 秘器：迅捷儀式（Haste Rituals） |

追獵者是為追蹤、摧毀特定敵機而設計的獵手。「追獵連結」初次鎖定時需要視線接觸，之後提供的追蹤卻準確、持久，而且極難擺脫。到了結束狩獵的時候，銳利的爪子往往就足以了結獵物。

### 動作：追獵連結（Pursuit-Bond）

你可以指定另一架看得見的阿斯提爾為目標。你會以超自然感知，隨時掌握它的位置。

### 武器

- **手持：鐮形利爪（Scything Claws）IV**：近戰／貼身、突襲（melee / intimate, blitz）。
- **搭載：儀式步槍（Ritual-Rifle）IV**：狙擊／搭載、耗能（sniper / mounted, drain）。

# 範例阿斯提爾：降臨

## 降臨（Advent）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 神聖 |
| 核心 | 古代 |
| 能量 | 3 |
| 狀態欄 | 過熱 |
| 零件 A | 秘器：反應增幅器（Reaction Enhancer） |
| 零件 B | 護禦：降臨金屬裝甲（Adventium Plate）；+守護（ward） |

降臨是傳奇般的設計。有些人說，它仿自一世紀前贏得大戰的阿斯提爾；另一些人則說，它就是當年那一架。這架白色機體的故事眾說紛紜，但無論所屬一方是對是錯，它似乎從不站在輸家那邊。

### 動作：降臨的傳承（Advent Legacy）

駕駛降臨「率領出擊」時，獲得優勢。

### 武器

- **手持：射線步槍（Rayrifle）III**：遠射／無限、雙手（ranged / infinite, 2H）。
- **收鞘：力能劍（Forceblade）III**：近戰／剋敵、耗能（melee / bane, drain）。

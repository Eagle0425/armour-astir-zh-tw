# 範例阿斯提爾：千變者

## 千變者（Protean）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 元素 |
| 核心 | 煉金 |
| 能量 | 1 |
| 狀態欄 | 過熱 |
| 零件 A | 變形連結：+適應（adapted，飛行形態） |
| 零件 B | 秘器：水銀形態（Quicksilver Form） |

千變者旨在成為靈活而均衡的萬事通。機體內部充滿煉金水銀，可隨時以魔法重新塑形，因此幾乎能適應任何情況。

### 動作：無常之形（Fickle Form）

你可以承受風險「不穩定」，使用「水銀形態」，不必花費能量啟動「子系統」。

### 武器

- **手持：水銀武庫（Quicksilver Armoury）III**：近戰／防禦、雙手（melee / defensive, 2H）。
- **搭載：水銀洪流（Mercurial Torrent）III**：遠射／範圍、剋敵、搭載、耗能 3（ranged / area, bane, mounted, drain 3）。

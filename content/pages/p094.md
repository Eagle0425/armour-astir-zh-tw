# 範例阿斯提爾：召喚者

## 召喚者（Summoner）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 奧術 |
| 核心 | 結晶 |
| 能量 | 2 |
| 狀態欄 | 過熱 |
| 零件 A | 秘器：使魔同步儀式（Familiar Sync Rituals） |
| 零件 B | 使魔矩陣：碎片使魔（Shard Familiars）III |

召喚者的設計目的是引導多方火力壓倒對手。它透過小型使魔網絡，在引導者指揮下協調射擊。為提升魔法輸出而特別強化的矩陣，讓它能操作真正成群的使魔。

### 動作：矩陣刷新（Refresh Matrix）

使魔加上 +突襲（blitz），移除 −有限（limited）。

### 武器

- **手持：劈砍斧（Cleaving Axe）III**：近戰（melee）。
- **矩陣：碎片使魔（Shard Familiars）III**：遠射／範圍、突襲（ranged / area, blitz）。

# 範例阿斯提爾：歌利亞

## III 階範例阿斯提爾

以下是依照前述自訂阿斯提爾規則製作的一組 III 階機體範例。

## 歌利亞（Goliath）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 凡俗 |
| 核心 | 古代 |
| 能量 | 2 |
| 狀態欄 | 過熱 |
| 零件 A | 抗性護符：堅守脛甲（Stalwart Greaves）；降低擊退或推擠造成的危難 |
| 零件 B | 護禦：泰坦裝甲（Titanic Armour）；+守護（ward） |

歌利亞的設計意圖簡單明確：成為盟友得以躲藏其後、絕不退讓的壁壘。厚重裝甲與更加厚重的盾牌讓這件事毫不費力；對歌利亞的引導者而言，戰爭的洪流不過是一條小溪。

### 動作：歌利亞之盾（Goliath Shield）

為了保護他人而「協助或妨礙」時，獲得優勢。

### 武器

- **手持：戰斧與盾（Battleaxe & Shield）III**：近戰／防禦、雙手（melee / defensive, 2H）。
- **搭載：烈焰魔杖（Blazewands）III**：遠射／剋敵、裝填、搭載、耗能（ranged / bane, reload, mounted, drain）。

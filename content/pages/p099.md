# 範例阿斯提爾：牡羊

## 牡羊（Aries）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 奧術 |
| 核心 | 煉金 |
| 能量 | 1 |
| 狀態欄 | 過熱 |
| 零件 A | 熱量凝縮器：清除阿斯提爾的「過熱」勾選 |
| 零件 B | 使魔矩陣：幽光使魔（Wisp Familiars）III |

牡羊的設計氣勢逼人，長著惡魔般的角，使魔則慣於聚成光環般的陣形。當然，最可怕的還是速度。魔法火焰之輪在地面燒出焦痕、推動機體前進；想逃離牡羊，可不是容易的事。

### 動作：魔力之輪（Manawheels）

過熱時，進行仰賴速度的動作，獲得優勢。

### 武器

- **手持：烈焰魔杖（Blazewands）III**：遠射／攻防兼備、裝填、耗能（ranged / versatile, reload, drain）。
- **手持：力能短刀（Forceknife）III**：近戰／剋敵、貼身（melee / bane, intimate）。
- **矩陣：微粒使魔（Mote Familiar）III**：狙擊／衝擊、剋敵、危險（sniper / impact, bane, dangerous）。

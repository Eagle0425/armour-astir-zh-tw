# 範例阿斯提爾：塔拉斯克

## 塔拉斯克（Tarrasque）III

| 欄位 | 內容 |
| --- | --- |
| 路數 | 褻瀆 |
| 核心 | 邪術 |
| 能量 | 0 |
| 狀態欄 | 過熱 |
| 零件 A | 秘器：混沌引擎（Chaos Engine） |
| 零件 B | 抗性護符：碎鏈者恩賜（Chainbreaker's Boon）；降低束縛或緩速造成的危難 |

塔拉斯克的駕駛者，不是勇者就是一心求死的人；這名聲不難理解。它幾乎只配備利爪和尾巴，由飢渴的混沌引擎驅動，是笨重又沒效率的一團亂。但只要你失誤一次，它就會活吞了你。肚裡有了一餐之後，這團亂就成了怪物。

### 動作：魔力吞噬者（Mana Devourer）

對另一架阿斯提爾成功「決定性打擊」、造成實體傷害時，+1 能量。

### 武器

- **手持：撕裂利爪（Rending Claws）III**：近戰／毀滅、耗能 2（melee / ruin, drain 2）。
- **搭載：新星尾（Novatail）III**：近戰／衝擊、搭載、耗能 2（melee / impact, mounted, drain 2）。

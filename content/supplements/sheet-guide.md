## 所有角色共用的欄位

| 英文欄位 | 中文與填寫內容 |
| --- | --- |
| 名字空格／The … | 角色姓名與扮演書。 |
| DEFY / SENSE / CLASH / TALK / KNOW | 抗逆／洞察／交鋒／交涉／才智的數值。 |
| You look / You wear | 你的樣貌／穿著。其他描述提示依扮演書填寫。 |
| Start With… / Gear / Tools | 起始內容／裝備／工具；標記已選的起始選項。 |
| Dangers / risk / peril | 危難／風險／險境；寫出危難內容並標記類型，不是只記數字。 |
| GRAVITY Clocks | 引力時鐘；記錄對象、關係、數值與六格進度，共享同一時鐘的人應同步。 |
| GRAVITY Trigger | 本扮演書額外推進引力的觸發條件；條文在各扮演書。 |
| Hooks / loose / deep | 三項牽引；標記鬆動／深刻。兩者皆未標記時為一般牽引。 |
| Spotlight /6 | 聚光，通常累積六點可花費換取成長；艙室等能力可能改變門檻。 |
| Starting Moves / Additional Moves | 起始動作／額外動作；依起始規則及成長標記已取得的動作。 |

## 引導者的機體欄位

| 英文欄位 | 中文與填寫內容 |
| --- | --- |
| CHANNEL | 引導；依扮演書規則計算。 |
| APPROACH | 徒步戰鬥的路數，依扮演書選項標記；機體另有自己的路數。 |
| Your magic is like… | 你的魔法呈現何種樣貌。 |
| When you launch your Astir, you say… | 阿斯提爾出擊時，你會說什麼？ |
| Astir | 機體名稱與記錄空間；可寫下零件、武裝與其他需要查閱的資料。 |
| CORE / POWER / OVERHEATING | 核心／能量／過熱；抄錄所選核心的數值與能力，並記錄目前狀態。 |

完整建造選項見[建造阿斯提爾](#astir)，不要把紙上空格當成額外提供的零件或能力。

## 支援者的艙室欄位

「Quarters」是**艙室**：描述你在母艦上的住所，從表單四項好處選兩項。這些選項的完整中文與限制已在[母艦與艙室](#carrier/p080)。

艦長另記領導方式，外交官記名聲，斥候記戰鬥方式與訂製武器，工匠記手作品風格。各自選項見上方對應扮演書。

角色卡統一印了三格危難；若能力改變可承受的數量，另註當前上限。例如艦長在指揮席上的特殊待遇，依[艦長核心規則](#captain)處理，不能因卡片只有三格就忽略能力。

## 母艦共用記錄表

來源：第 17 頁。先由全桌決定路數，再處理武器；完整建造規則見[母艦與艙室](#carrier)。

| 英文欄位 | 中文與填寫內容 |
| --- | --- |
| The CARRIER 名字空格 | 母艦名稱。 |
| CREW | 艦員數值；用於需要 +艦員的動作。 |
| Carrier Type | 移動類型：飛行／陸行／水行／複合。 |
| Carrier Approach | 母艦路數：奧術／神聖／褻瀆／元素／凡俗。 |
| Carrier Weapons | 母艦武器；記階級、射程、標籤與敘事描述。 |
| Clocks | 時鐘；寫明追蹤的目標、格數與進度。 |
| Notes | 備註；可記艙室、艦員、改裝與重要事件。這是使用建議，不是額外規則。 |

武器區提示：階級 V 主武器選遠射或狙擊，標籤成本合計 +2，另有架設與搭載；階級 III 副武器選遠射或狙擊，標籤成本合計 +1，另有搭載。說明主武器為何受限，副武器如何保衛近處，以及武器裝在哪裡、由誰或何種魔法控制。完整規則及標籤見[母艦武器](#carrier/p080)、[標籤與取得裝備](#tags)。

## 使用角色卡前確認版本

第 4 頁「解放」與第 16 頁「奧術發電機」的文字，與網站採用的核心書不同。請先看[配套文件版本差異](#version-notes)，不要將兩版效果合併。

# 擲骰狀態來源速查

依《Reference_Sheets》第 10 頁的集中來源清單整理，並逐項對回核心書。原表把「優勢與自信」及「劣勢與絕境」各列成一組；下表拆開機制，方便桌上查找。

## 先認清四種效果

| 狀態 | 如何改變骰子 |
| --- | --- |
| 優勢 | 多擲骰，保留最高兩顆。 |
| 劣勢 | 多擲骰，保留最低兩顆。 |
| 自信 | 每顆 1 視為 6。 |
| 絕境 | 每顆 6 視為 1。 |

優勢或劣勢通常擲 3d6，可疊加但最多 4d6，且互相抵銷。先套用自信或絕境，再決定保留哪兩顆。完整例子見[擲骰規則](#concepts/p009)。

## 不利來源

| 原表列出的來源 | 核心書中的效果 | 查閱 |
| --- | --- | --- |
| 戰鬥時，目標的路數克制你 | 絕境。 | [路數](#conflict-tiers/p066) |
| 已有三項危難，又承受危難 | 不能一概當成所有動作都在絕境；依危難種類與是否仍有風險可替換處理，見下方。 | [危難](#concepts/p013) |
| 別人成功「妨礙」你 | 你的擲骰有劣勢。 | [協助或妨礙](#help-or-hinder) |
| 扮演書動作 | 依個別動作；劣勢不自動等於絕境。 | [扮演書](#playbooks) |

**危難溢出的精確條件：**已有三項危難，再承受風險時，把其中一項改成險境；再陷入險境時，若仍有風險就以它替換。若已無風險可換，直到本次出擊結束，擲「倒下」時都在絕境中擲骰；進一步危難改為觸發「倒下」。原表的短句省略了這些分支。

## 路數克制一眼查

**凡俗 → 奧術 → 神聖 → 褻瀆 → 元素 → 凡俗。**箭頭前者克制後者：對它作戰有自信；反向對抗則在絕境中。

這是原參考表的來源彙整，不是所有可能來源的完整清單。裝備標籤、情境與其他動作仍依[核心書](#concepts/p009)及各自條文判定。

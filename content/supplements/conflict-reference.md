# 衝突回合主持速查

依《AAA_ConflictTurnRef》第 1 頁的回合概要與第 4 頁成果摘要整理。這是供全桌使用的主持流程；六種場景的挑戰、收束與勢力成果已在正文，以連結直接查閱。

## 每個部門跑一次

標準威權有一個主要部門（5+）與兩個次要部門（4+）；每回合各演一場衝突場景。若「籌畫與準備」等效果暫時改變實力，使用調整後的值。

1. **選場景、耗竭派系**：選一個衝突場景，指定代表義軍利益的派系並耗竭它。選到已耗竭的派系會使它被摧毀。
2. **沒有投入派系？** 若不願或無法投入，仍演出場景，但收束時自動由威權獲勝。
3. **依場景演出與擲骰**：按場景指示分配角色、提出挑戰；需要擲骰時擲一顆 d6。達到或超過部門實力算義軍成功，否則算威權成功。扮演威權角色時，擲骰失敗可能反而符合你的角色利益。
4. **需要自動成功？** 可耗竭派系跳過一次擲骰，為義軍增加一次成功；注意耗竭與摧毀的規則。
5. **比較、收束、選成果**：依成功與失敗次數決定勝方，選符合場景的收束，再由勝方取得一項成果。

此處勝負與平手依[核心書收束規則](#conflict-turn/p114)：成功較多為義軍勝，失敗較多為威權勝；平手全體共同詮釋，不確定時擲硬幣。參考表第 4 頁的壓縮措辭另列於[版本差異](#version-notes)。

## 開場與收場要翻哪裡

| 當下需要 | 查閱位置 |
| --- | --- |
| 選場景、分角色、找挑戰及收束問題 | [六種衝突場景](#conflict-scenes) |
| 檢查部門實力、支柱與穩定度 | [部門](#conflict-turn/p106) |
| 查派系耗竭、摧毀及掌控 | [派系](#conflict-turn/p109) |
| 威權勝：從該部門類型選成果 | [部門類型與成果](#conflict-turn/p107) |
| 義軍勝：選參與本場景的派系，取得其成果 | [派系類型與成果](#conflict-turn/p110) |
| 檢查收束、平手與結果如何傳回主角 | [收束衝突場景與成果](#conflict-turn/p114) |

義軍可選的派系，包含起初投入的派系及為跳過擲骰而耗竭的派系。可以為預想的成果設計場景，但不必事先鎖定成果。

最後，把回合事件帶回角色所知的世界。休整時的報紙、報導或人物轉述，都是傳達戰局改變的機會。
